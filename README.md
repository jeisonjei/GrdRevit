# Применить данные из Audytor — плагин Revit

Плагин Revit для подбора и применения типа отопительного прибора к
выделенному механическому оборудованию. Основной рабочий путь строится на
двух текстовых выписках: **«помещения и радиаторы»** (`room-radiator.txt`) и
**«настройки клапанов»** (`valve-settings.txt`). Загрузка двоичного файла
`.grd` (ПВФ / TEPLA) сохранилась как унаследованный путь и **в текущей
конфигурации не активна**.

## Возможности

- Загрузка приборов из `room-radiator.txt`: код прибора, помещение, тепловая
  мощность (Фhl, Вт), диаметр. Тип прибора распознаётся по коду
  (TEPLA Classic Plus/DG/NEO EXPO, HZ, GS и пр.).
- Загрузка `valve-settings.txt` на отдельную вкладку **«Valve Settings»**
  (только просмотр): помещение, диаметр, код прибора, настройка клапана, Kv,
  мощность.
- Сопоставление настроек клапанов строкам таблицы по ключу
  «помещение + мощность (Вт)» — кнопка **«Fill valve settings column»**.
- Применение типа осуществляется **только** кнопкой **«Применить»** в строке
  таблицы (одиночный/двойной клик по строке тип не применяет).
- Кнопки строк активны, только когда в проекте выделено **ровно одно**
  механическое оборудование.
- «Применить тип» подбирает точное имя типа семейства (по мощности/имени),
  применяет **тип семейства** и **параметры экземпляра** из настроек.
- Если семейство выделенного элемента отличается от целевого — элемент
  заменяется новым экземпляром целевого семейства на том же месте
  (уровень сохраняется).
- Всплывающие уведомления (SnackBar) в правом нижнем углу после успешных
  действий (загрузка, сопоставление, применение).

## Форматы входных файлов

Оба файла — текстовые, разделитель — табуляция, кодировка UTF-8.

`room-radiator.txt` (колонки, индексация с 0):

| Колонка | Содержимое                              |
|---------|-----------------------------------------|
| 0       | Помещение (например, «БКТ 102»)         |
| 1       | Код / номер помещения                   |
| 3       | Код прибора (например, `TPLNE2518T2L`)  |
| 4       | Длина, м                                |
| 5       | Диаметр, мм                             |
| 6       | Тепловая мощность Фhl, Вт               |

`valve-settings.txt` (колонки, индексация с 0):

| Колонка | Содержимое                                        |
|---------|---------------------------------------------------|
| 0       | Помещение                                         |
| 1       | Диаметр, мм                                       |
| 2       | Код клапана/прибора (`КТС-ВП2`, `D-2500015`, …)   |
| 3       | Настройка клапана (значение подставляется в таблицу) |
| 5       | Kv (пропускная способность)                      |
| 6       | Тепловая мощность, Вт (ключ сопоставления)        |

## Поддерживаемые версии Revit

| Сборка             | Revit      | RevitAPI    |
|--------------------|------------|-------------|
| `net48`            | 2020–2024  | Revit 2024  |
| `net8.0-windows`   | 2025–2026  | Revit 2026  |

> NET48-сборка компилируется против API Revit 2024 и использует только
> стабильные члены API, поэтому работает на Revit 2020–2024.
> NET8-сборка работает на Revit 2025–2026.

## Сборка и установка

```powershell
# собрать (оба таргета)
.\build\build.ps1

# собрать и подготовить dist\Revit2024, dist\Revit2026, dist\GrdInstaller.exe
.\build\build.ps1 -Publish
```

### Быстрая установка через GrdInstaller.exe

`dist\GrdInstaller.exe` — самодостаточный установщик (одна копия плагина
внутри .exe, не требует .NET 8 и папки dist). Дважды щёлкните:

1. Установщик найдёт все установленные версии Revit (2020–2026) и выведет их списком.
2. Отметьте нужные, нажмите **«Установить выбранные»** — плагин появится
   во вкладке **ГРД** после перезапуска Revit.
3. Если Revit уже запущен — установщик предупредит и предложит перезапустить его.

Silent-режим:

```powershell
GrdInstaller.exe -silent -install      # установить во все найденные версии
GrdInstaller.exe -silent -uninstall    # удалить
```

> **Почему нужен перезапуск Revit:** внешние приложения Revit
> (`IExternalApplication`) загружаются только при старте из манифестов
> `.addin`. Публичного API для «горячей» подгрузки нового приложения в
> уже запущенный Revit не существует — это ограничение Revit API.
> Установщик просто перезапускает Revit за вас.

Установщик пишет:

- `.addin` — в `%APPDATA%\Autodesk\Revit\Addins\<год>\GrdRevit.addin`,
- DLL плагина — в `%LOCALAPPDATA%\GrdRevit\<год>\`,
- настройки — в `%APPDATA%\GrdRevit\settings.json`.

### Ручная установка

1. Скопируйте `dist\Revit2024\Addins\2024.addin`
   в `%APPDATA%\Autodesk\Revit\Addins\2024\`.
2. Там же измените путь `<Assembly>` на абсолютный путь
   к `dist\Revit2024\GrdRevit.dll` (или оставьте как есть, если папка не переезжала).
3. Аналогично для 2026: `%APPDATA%\Autodesk\Revit\Addins\2026\`.

## Использование

1. Ribbon-вкладка **«ГРД» → «Отопительные приборы СО»**.
2. **«Load Rooms and Radiators...»** — выбрать `room-radiator.txt`;
   таблица **«Отопительные приборы СО»** заполняется приборами.
3. **«Load Valve Settings»** — выбрать `valve-settings.txt`; на вкладке
   **«Valve Settings»** отображаются строки настроек клапанов.
4. **«Fill valve settings column»** — заполнить колонку
   **«Настройка клапана»** в таблице приборов (сопоставление по помещению
   и мощности; при нескольких приборах на комнату пары образуются по порядку).
5. В активном проекте Revit выделите **одно** механическое оборудование.
6. Нажмите **«Применить»** в нужной строке.

Настройки (`%APPDATA%\GrdRevit\settings.json`):

- **Параметры экземпляра**: имя + значение + тип. Подстановки `{W}`, `{кВт}`, `{code}`.
- **Точная карта**: код -> точное имя типа семейства.
- **Переопределение семейства**: префикс кода -> имя семейства.

Последние пути загруженных файлов запоминаются и подставляются как
начальный каталог диалогов выбора.

## Структура

```
src/Grd.Core     Парсеры текстовых файлов, модель данных, коды приборов,
                 сопоставление настроек, настройки (netstandard2.0)
src/Grd.Revit    IExternalApplication/IExternalCommand, WPF-интерфейс,
                 применение типов, SnackBar (net48 + net8.0-windows)
tests            Модульные тесты GrdRevit.Core.Tests (xUnit)
tools/Grd.Dump   Консоль проверки парсера: dotnet run --project tools/Grd.Dump -- <file.grd>
tools/Grd.Installer   Самодостаточный установщик (net48 WinForms, DLL плагина в ресурсах)
addins           Шаблоны .addin
build/build.ps1  Скрипт сборки/публикации
```

Тесты парсеров и сопоставления настроек:

```powershell
dotnet test tests\GrdRevit.Core.Tests\GrdRevit.Core.Tests.csproj -c Release
```

Проверка парсера `.grd` на реальном файле (унаследованный путь):

```powershell
dotnet run --project tools\Grd.Dump\Grd.Dump.csproj -- "C:\path\file.grd"
```

> **Кодировки (унаследованный путь .grd):** `.grd` — UTF-16LE (текст
> токенами через `00`), `.grr` — однобайтовый CP1251. Общая сигнатура
> `PWFILEVERINFST___DAT7.00`/`RES7.00` (`AUDYTOR 7.3`, набор `SET_7_0`).
> Подробнее — `docs/FORMAT.md`.

## Формат кодов приборов .grd

- `TPLCPL714T2L` → TEPLA Classic Plus, 714 Вт, двухтрубное (T2L)
- `TPLCDG1611` → TEPLA Classic DG, 1611 Вт
- `TPLNE1969T2L` → TEPLA NEO EXPO, 1969 Вт
- `HZ-814` / `HZ 814` → 814 Вт (одно и то же)
- `GS-4-80` → стальная панельная GS

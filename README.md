# ГрД — отопительные приборы СО (Revit plugin)

Плагин Revit для загрузки файла `.grd` (ПВФ / TEPLA / «проектные диаметры»),
отображения отопительных приборов по типам и применения выбранного типа
к выделенному единственному механическому оборудованию.

## Возможности

- Парсинг `.grd` как UTF-16LE потока: комнаты/стояки, приборы (TEPLA Classic Plus/DG/NEO EXPO, HZ, GS).
- Таблица на вкладке **«Отопительные приборы СО»**: код, тип, мощность (кВт), количество, соседние помещения.
- Кнопки строк активируются, когда выделено **ровно одно механическое оборудование**.
- Нажатие кнопки «Применить тип» применяет **тип семейства** (подбор по мощности/имени)
  и **параметры экземпляра** из настроек.
- Если семейство выделенного элемента отличается — старый элемент заменяется
  новым экземпляром целевого семейства на том же месте (уровень сохраняется).
- Вкладка «Трубопроводная арматура» зарезервирована под крепления/арматуру.

## Поддерживаемые версии Revit

| Сборка | Revit | RevitAPI |
|--------|-------|----------|
| `net48` | 2020–2024 | Revit 2024 |
| `net8.0-windows` | 2025–2026 | Revit 2026 |

> NET48-сборка компилируется против API Revit 2024 и использует только
> стабильные члены API, поэтому работает на Revit 2020–2024.
> NET8-сборка работает на Revit 2025–2026.

## Сборка и установка

```powershell
# собрать (оба таргета)
.\build\build.ps1

# собрать и подготовить dist\Revit2024, dist\Revit2026, dist\GrdInstaller.exe
.\build\build.ps1 -Publish
```

### Быстрая установка через GrdInstaller.exe

`dist\GrdInstaller.exe` — самодостаточный установщик (одна копия плагина прямо в .exe,
не требует .NET 8 и папки dist). Дважды щёлкните:

1. Установщик найдёт все установленные версии Revit (2020–2026) и выведет их списком.
2. Отметьте нужные, нажмите **«Установить выбранные»** —
   плагин появится во вкладке **ГРД** после перезапуска Revit.
3. Если Revit уже запущен — установщик предупредит и предложит перезапустить его.

Silent-режим:

```powershell
GrdInstaller.exe -silent -install      # установить во все найденные версии
GrdInstaller.exe -silent -uninstall    # удалить
```

> **Почему нужен перезапуск Revit:** внешние приложения Revit (`IExternalApplication`)
> загружаются только при старте из манифестов `.addin`. Публичного API для
> «горячей» подгрузки нового приложения в уже запущенный Revit не существует —
> это ограничение Revit API. Установщик просто перезапускает Revit за вас.

Установщик пишет:
- `.addin` — в `%APPDATA%\Autodesk\Revit\Addins\<год>\GrdRevit.addin`,
- DLL плагина — в `%LOCALAPPDATA%\GrdRevit\<год>\`,
- настройки — в `%APPDATA%\GrdRevit\settings.json`.

### Ручная установка

1. Скопируйте `dist\Revit2024\Addins\2024.addin`
   в `%APPDATA%\Autodesk\Revit\Addins\2024\`.
2. Там же измените путь `<Assembly>` на абсолютный путь
   к `dist\Revit2024\GrdRevit.dll` (или оставьте как есть, если папка не переезжала).
3. Аналогично для 2026: `%APPDATA%\Autodesk\Revit\Addins\2026\`.

## Использование

1. Ribbon-вкладка **«ГРД» → «Отопительные приборы СО»**.
2. Выберите файл `.grd`.
3. В активном проекте Revit выделите **одно** механическое оборудование.
4. Нажмите **«Применить тип»** в нужной строке.

Настройки (`%APPDATA%\GrdRevit\settings.json`):

- **Параметры экземпляра**: имя + значение + тип. Подстановки `{W}`, `{кВт}`, `{code}`.
- **Точная карта**: код -> точное имя типа семейства.
- **Переопределение семейства**: префикс кода -> имя семейства.

## Структура

```
src/Grd.Core     Парсер .grd, модель данных, коды приборов, настройки (netstandard2.0)
src/Grd.Revit    IExternalApplication/IExternalCommand, WPF, применение типов (net48 + net8.0-windows)
tools/Grd.Dump   Консоль проверки парсера: dotnet run --project tools/Grd.Dump -- <file.grd>
tools/Grd.Installer   Самодостаточный установщик (net48 WinForms, DLL плагина в ресурсах)
addins           Шаблоны .addin
build/build.ps1  Скрипт сборки/публикации
```

Проверка парсера на реальном файле:

```powershell
dotnet run --project tools\Grd.Dump\Grd.Dump.csproj -- "C:\path\..........grd"
```

Конвертация в понятный файл-результат:

```powershell
# .grd → clean.txt (читаемый отчёт) + devices.csv (таблица приборов): рядом с исходником
dotnet run --project tools\Grd.Dump\Grd.Dump.csproj -- "C:\path\..........grd" --exports

# .grr → то же самое (чистая структура: приборы/трубы/арматура/справочник)
dotnet run --project tools\Grd.Dump\Grd.Dump.csproj -- grr "C:\path\..........grr"

# явные пути вывода
dotnet run --project tools\Grd.Dump\Grd.Dump.csproj -- "file.grd" --exports --txt out.txt --csv out.csv

# регрессия парсера: счётчики должны совпасть
dotnet run --project tools\Grd.Dump\Grd.Dump.csproj -- --verify "file.grd" --runs 8397 --rooms 218 --devices 909 --types 61
```

> **Кодировки:** `.grd` — UTF-16LE (текст токенами через `00`),
> `.grr` — однобайтовый CP1251. Общая сигнатура `PWFILEVERINFST___DAT7.00`/`RES7.00`
> (`AUDYTOR 7.3`, набор `SET_7_0`). Подробнее — `docs/FORMAT.md`.

## Формат кодов приборов .grd

- `TPLCPL714T2L` → TEPLA Classic Plus, 714 Вт, двухтрубное (T2L)
- `TPLCDG1611` → TEPLA Classic DG, 1611 Вт
- `TPLNE1969T2L` → TEPLA NEO EXPO, 1969 Вт
- `HZ-814` / `HZ 814` → 814 Вт (одно и то же)
- `GS-4-80` → стальная панельная GS
